FontSnap 是一款直接在 Chrome 中运行的 AI 图片字体识别工具（font identifier from image）。在网站、横幅或截图里看到好看的字体？框选文字或右键点击图片，这款图片字体识别工具就会显示 5 款最相似的 Google 字体。

🚀 3 步完成图片字体识别
1️⃣ 点击工具栏中的 FontSnap 图标，或按 Alt+Shift+F。
2️⃣ 在一两行文字上拖出一个矩形，或右键点击图片并选择识别此图片中的字体。
3️⃣ 查看前 5 个匹配结果，附带效果预览和匹配分数。

无需账号，无需上传到服务器。神经网络在本地运行，因此这款图片字体识别工具会让您的图片始终留在您的电脑上。

🔍 FontSnap 有何不同
大多数同类扩展只读取 CSS，遇到徽标、图片、横幅和 canvas 文字就无能为力。FontSnap 分析的是像素而不是代码，因此在 CSS 无法提供信息的地方也能使用：
• 图片、海报和社交媒体配图中的文字
• 应用、幻灯片和 PDF 页面的截图
• 任何网站上的首屏横幅和广告

📌 主要功能
- 在任意网页上框选区域：只需在文字上拖动。
- 右键菜单：在任意网站上一键完成图片字体识别。
- 上传模式，一款以图找字体的查找工具：按 Ctrl+V 粘贴、拖入文件或选择图片。
- 显示 5 款最相似的结果及匹配分数。
- 用您自己的示例文字预览每个匹配结果。
- 一键复制现成的 CSS 代码。
- 支持拉丁文、西里尔文和阿拉伯文。

🧠 基于数千种样式训练的 AI 字体查找工具
FontSnap 使用一个紧凑的字体识别模型，训练数据涵盖 3600 多种字体样式。它会把样式归并为字体家族，给出简洁清晰的列表。因此它是一款实用的匹配和识别工具：哪怕原字体是商业字体，您也能得到今天就能使用的最接近的替代品。

➤ 需要为客户设计稿匹配字体的网页设计师。
➤ 想要 CSS 代码而不只是名称的前端开发者。
➤ 需要复刻横幅风格的营销人员和 SMM 运营人员。
➤ 总在问这是什么字体的学生和博主。
➤ 想从图片中查出字体名称、又不想安装笨重桌面软件的所有人。
➤ 需要对扫描件和截图进行以图找字体的研究人员。

⚡ 为什么在线图片字体识别并不总是够用
网页工具需要您保存、上传并裁剪图片。FontSnap 省去了这些步骤：
▸ 直接在您正在浏览的页面上框选；
▸ 页面上的图片只需右键点击；
▸ 结果会在原页面旁边的新标签页中打开。
这是一款融入浏览器的图片字体识别工具，而不是让您绕道离开浏览器。

📊 字体检测器与 CSS 检查器
CSS 检查器可以读取网页真实文字的样式，但看不到 JPG 或 canvas 中的文字。基于图像的检测器正好弥补了这一点。

🔒 隐私优先
▸ 图像分析通过 WebAssembly 在设备上完成。
▸ 您的截图永远不会离开浏览器。
▸ 仅向 Google Fonts 请求字体家族名称用于预览。
▸ 无追踪、无广告、无需注册。

💡 获得准确结果的技巧
• 选择一两行文字，而不是整个页面。
• 只拖选屏幕上可见的文字：选区只截取当前视口，不会包含滚出屏幕的内容。
• 大字号文字比细小的说明文字识别得更准确。
• 如果首个结果看起来不对，请查看其余四个：正确答案往往就在前 5 名中。

❓ 常见问题
📍 FontSnap 是什么？
这是一款 Chrome 扩展，也是一款 AI 图片字体识别工具，可以识别屏幕选定区域、网页图片或上传图片中的字体。

📍 如何识别图片文件中的字体？
在任意网页上打开 FontSnap，切换到上传模式，然后粘贴、拖入或选择一张包含文字的图片。

📍 可以不保存就检查网页上的图片吗？
可以。右键点击图片并选择识别此图片中的字体。

📍 FontSnap 可以离线使用吗？
识别本身在本地运行。只有从 Google Fonts 加载预览时才需要联网。

📍 能识别商业字体吗？
FontSnap 与 Google Fonts 字体家族进行比对。对于商业字体，它会显示 Google Fonts 中最接近的替代字体，这往往正是网页项目所需要的。

📍 支持哪些文字？
拉丁文、西里尔文和阿拉伯文的结果最准确。中文和日文的支持目前仍有限。

📍 会收集我的数据吗？
不会。该扩展不收集任何个人数据，也不会把您的图片发送到任何地方。
