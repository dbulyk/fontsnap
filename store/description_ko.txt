FontSnap은 Chrome 안에서 작동하는 AI 글꼴 식별기로, 이미지로 폰트 찾기(font identifier from image)를 도와줍니다. 웹사이트, 배너, 스크린샷에서 멋진 글꼴을 발견하셨나요? 텍스트 위에 상자를 그리거나 이미지를 마우스 오른쪽 버튼으로 클릭하면, 이 글꼴 식별기가 가장 비슷한 Google 폰트 5개를 보여줍니다.

🚀 이미지로 폰트 찾기, 3단계면 충분합니다
1️⃣ 도구 모음의 FontSnap 아이콘을 클릭하거나 Alt+Shift+F를 누릅니다.
2️⃣ 한두 줄의 텍스트 위로 사각형을 드래그하거나, 이미지를 마우스 오른쪽 버튼으로 클릭해 이 이미지의 글꼴 식별을 선택합니다.
3️⃣ 라이브 미리보기와 일치 점수가 표시되는 상위 5개 결과를 확인합니다.

계정도, 서버 업로드도 필요 없습니다. 신경망이 로컬에서 실행되므로 이미지로 폰트 찾기를 하는 동안에도 이미지는 내 컴퓨터에 그대로 남습니다.

🔍 FontSnap이 다른 점
이런 종류의 확장 프로그램 대부분은 CSS만 읽기 때문에 로고, 이미지, 배너, canvas 텍스트에서는 작동하지 않습니다. FontSnap은 코드가 아닌 픽셀을 보기 때문에 CSS로 알 수 없는 곳에서도 작동합니다.
• 이미지, 포스터, SNS 그래픽 속 텍스트
• 앱, 슬라이드, PDF 페이지의 스크린샷
• 모든 웹사이트의 히어로 배너와 광고

📌 주요 기능
- 모든 페이지에서 영역 선택: 텍스트 위로 드래그하기만 하면 됩니다.
- 오른쪽 클릭 메뉴: 어떤 웹사이트에서든 클릭 한 번으로 이미지에서 폰트 찾기.
- 이미지로 폰트 찾기 전용 업로드 모드: Ctrl+V로 붙여넣기, 파일 끌어다 놓기 또는 이미지 선택.
- 일치 점수와 함께 가장 비슷한 폰트 5개 표시.
- 원하는 문구로 각 결과를 라이브 미리보기.
- 완성된 CSS 한 줄을 클릭 한 번으로 복사.
- 라틴 문자, 키릴 문자, 아랍 문자 지원.

🧠 수천 개 스타일로 학습해 이미지로 폰트 찾기를 돕는 AI
FontSnap은 3,600개 이상의 글꼴 스타일로 학습한 경량 글꼴 인식 모델을 사용합니다. 스타일을 패밀리 단위로 묶어 짧고 깔끔한 목록으로 보여줍니다. 그래서 실용적인 폰트 매칭 도구로 쓸 수 있습니다. 원래 글꼴이 유료라도 지금 쓸 수 있는 가장 가까운 대안을 얻을 수 있습니다.

🎨 이미지로 폰트 찾기를 쓰는 분들
➤ 클라이언트 시안에 맞는 폰트가 필요한 웹 디자이너
➤ 폰트 이름뿐 아니라 CSS가 필요한 프론트엔드 개발자
➤ 배너 스타일을 재현하려는 마케터와 SMM 담당자
➤ 이 폰트 뭐지? 하고 늘 궁금한 학생과 블로거
➤ 무거운 데스크톱 앱 없이 이미지에서 폰트 이름을 알아내고 싶은 모든 분
➤ 스캔 이미지와 스크린샷에서 이미지로 폰트 검색을 하는 연구자

⚡ 온라인 글꼴 식별기만으로는 부족한 이유
웹 도구는 이미지를 저장하고, 업로드하고, 잘라내야 합니다. FontSnap은 그 과정을 건너뜁니다.
▸ 지금 보고 있는 페이지에서 영역을 선택하고
▸ 페이지 속 이미지는 마우스 오른쪽 클릭 한 번이면 충분하며
▸ 결과는 원래 탭 옆의 새 탭에서 열립니다.
브라우저를 벗어나지 않고 이미지로 폰트 찾기를 끝낼 수 있습니다.

📊 글꼴 감지기와 CSS 검사기의 차이
CSS 검사기는 페이지의 실제 텍스트 스타일은 읽지만 JPG나 canvas 속 텍스트는 보지 못합니다. 이미지로 폰트 찾기에 특화된 글꼴 감지기가 그 빈틈을 채웁니다.

🔒 개인정보 보호 우선
▸ 이미지 분석은 WebAssembly로 기기에서 실행됩니다.
▸ 스크린샷은 브라우저 밖으로 나가지 않습니다.
▸ 미리보기를 위해 Google Fonts에는 패밀리 이름만 요청합니다.
▸ 추적, 광고, 가입이 없습니다.

💡 정확한 결과를 위한 팁
• 페이지 전체가 아닌 한두 줄의 텍스트를 선택하세요.
• 화면에 보이는 텍스트만 드래그하세요. 선택 영역은 현재 보이는 화면만 캡처하며, 화면 밖으로 스크롤된 내용은 포함되지 않습니다.
• 작은 캡션보다 큰 텍스트가 더 정확합니다.
• 첫 번째 추측이 맞지 않으면 나머지 네 개도 확인하세요. 정답이 상위 5개 안에 있는 경우가 많습니다.

❓ 자주 묻는 질문
📍 FontSnap은 무엇인가요?
화면에서 선택한 영역, 웹페이지 속 이미지, 업로드한 이미지의 글꼴을 인식하는 Chrome 확장 프로그램이자 AI 글꼴 식별기입니다.

📍 이미지로 폰트 찾기는 어떻게 하나요?
아무 페이지에서나 FontSnap을 열고 업로드 모드로 전환한 다음, 텍스트가 있는 이미지를 붙여넣거나 끌어다 놓거나 선택하세요.

📍 웹사이트의 이미지를 저장하지 않고 확인할 수 있나요?
네. 이미지를 마우스 오른쪽 버튼으로 클릭하고 이 이미지의 글꼴 식별을 선택하세요.

📍 오프라인에서도 작동하나요?
인식 자체는 로컬에서 실행됩니다. 인터넷은 Google Fonts에서 미리보기를 불러올 때만 사용됩니다.

📍 유료 글꼴도 인식하나요?
FontSnap은 Google Fonts 패밀리와 비교합니다. 유료 글꼴의 경우 Google Fonts에서 가장 가까운 대안을 보여주며, 웹 프로젝트에는 대개 이것으로 충분합니다.

📍 어떤 문자를 지원하나요?
라틴 문자, 키릴 문자, 아랍 문자가 가장 정확합니다. 중국어와 일본어 지원은 아직 제한적입니다.

📍 내 데이터가 수집되나요?
아니요. 이 확장 프로그램은 개인 데이터를 수집하지 않으며 이미지를 어디에도 보내지 않습니다.

🌟 일상적인 디자인 작업을 위한 이미지로 폰트 찾기 도구 FontSnap을 설치하고, 이 폰트 뭐지? 하는 순간을 명확한 답으로 바꾸세요. 텍스트를 선택하고, 결과를 확인하고, CSS를 복사한 뒤 디자인을 이어가세요.
