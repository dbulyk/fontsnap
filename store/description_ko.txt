FontSnap은 Chrome 안에서 바로 작동하는 AI 이미지 폰트 찾기 도구입니다. 웹사이트, 배너, 스크린샷에서 멋진 글꼴을 발견하셨나요? 텍스트 위에 상자를 그리기만 하면 FontSnap이 약 1초 만에 가장 비슷한 Google 폰트 5개를 보여줍니다.

🚀 3단계로 이미지에서 폰트 찾기
1️⃣ 도구 모음의 FontSnap 아이콘을 클릭하거나 Alt+Shift+F를 누릅니다.
2️⃣ 한두 줄의 텍스트 위로 사각형을 드래그합니다.
3️⃣ 실시간 미리보기와 신뢰도 막대가 있는 상위 5개 결과를 확인합니다.

계정 없이, 서버 업로드 없이, 기다림 없이. 신경망이 로컬에서 실행되므로 이미지는 내 컴퓨터에 그대로 남습니다.

🔍 FontSnap이 다른 점
이런 종류의 확장 프로그램 대부분은 CSS만 읽기 때문에 로고, 이미지, 배너, canvas 텍스트에서는 작동하지 않습니다. FontSnap은 코드가 아닌 픽셀을 보기 때문에 CSS로 알 수 없는 곳에서도 작동합니다.
• 이미지, 포스터, SNS 그래픽 속 텍스트
• 앱, 슬라이드, PDF 페이지의 스크린샷
• 모든 웹사이트의 배너와 광고
• 클라이언트가 채팅으로 보낸 시안

📌 주요 기능
- 모든 페이지에서 영역 선택: 텍스트 위로 드래그하기만 하면 됩니다.
- 업로드 모드: Ctrl+V로 붙여넣기, 파일 끌어다 놓기 또는 이미지 선택.
- 신뢰도 점수와 함께 가장 비슷한 폰트 5개 표시.
- 원하는 텍스트로 각 결과를 실시간 미리보기.
- 바로 쓸 수 있는 CSS를 클릭 한 번으로 복사.
- 라틴 문자, 키릴 문자, 아랍 문자 지원.

🧠 수천 개 폰트 패밀리로 학습한 AI 글꼴 식별기
FontSnap은 3,600개 이상의 글꼴 스타일로 학습한 경량 이미지 인식 모델을 사용합니다. 스타일을 패밀리 단위로 묶어 거의 같은 결과 수십 개 대신 짧고 깔끔한 목록을 보여줍니다. 원래 글꼴이 유료라도 지금 바로 쓸 수 있는 가장 가까운 대안을 얻을 수 있습니다.

🎨 이런 분들이 사용합니다
➤ 클라이언트 시안의 폰트를 빠르게 찾아야 하는 웹 디자이너
➤ 폰트 이름뿐 아니라 CSS가 필요한 프론트엔드 개발자
➤ 배너 스타일을 재현하려는 마케터와 SNS 담당자
➤ "이 폰트 뭐지?"가 늘 궁금한 학생과 블로거
➤ 무거운 데스크톱 앱 없이 이미지로 폰트를 찾고 싶은 모든 분
➤ 로고와 패키지에서 폰트 조합을 수집하는 타이포그래피 애호가

⚡ 온라인 도구만으로는 부족한 이유
웹 도구는 이미지를 저장하고, 업로드하고, 잘라내야 합니다. FontSnap은 그 과정을 건너뜁니다.
▸ 지금 보고 있는 페이지에서 바로 선택하고
▸ 마우스를 놓는 순간 식별이 시작되며
▸ 결과는 원래 탭 옆의 새 탭에서 열립니다.
브라우저를 벗어나지 않고 쓰는 폰트 식별 도구입니다.

📊 글꼴 식별기와 CSS 검사기의 차이
CSS 검사기는 페이지의 실제 텍스트 스타일은 읽지만 JPG나 canvas 속 텍스트는 보지 못합니다. 이미지 기반 글꼴 식별기가 그 빈틈을 채웁니다. 실제 텍스트에는 CSS를, 이미지에는 FontSnap을 함께 사용하세요.

🔒 개인정보 보호 우선
▸ 이미지 분석은 WebAssembly로 기기에서 실행됩니다.
▸ 스크린샷은 브라우저 밖으로 나가지 않습니다.
▸ 미리보기를 위해 Google Fonts에는 패밀리 이름만 요청합니다.
▸ 추적, 광고, 가입이 없습니다.

💡 정확한 결과를 위한 팁
• 페이지 전체가 아닌 한두 줄의 텍스트를 선택하세요.
• 작은 캡션보다 큰 텍스트가 더 정확합니다.
• 첫 번째 결과가 맞지 않으면 나머지 네 개도 확인하세요. 정답이 상위 5개 안에 있는 경우가 많습니다.

❓ 자주 묻는 질문
📍 FontSnap은 무엇인가요?
화면에서 선택한 영역이나 업로드한 이미지의 글꼴을 인식하는 Chrome 확장 프로그램이자 AI 글꼴 식별기입니다.

📍 이미지 파일의 폰트는 어떻게 찾나요?
아무 페이지에서나 FontSnap을 열고 업로드 모드로 전환하거나, Chrome 설정 같은 제한된 페이지에서 엽니다. 텍스트가 있는 이미지를 붙여넣거나 끌어다 놓거나 선택하세요.

📍 오프라인에서도 작동하나요?
인식 자체는 로컬에서 실행됩니다. 인터넷은 Google Fonts에서 미리보기를 불러올 때만 사용됩니다.

📍 유료 글꼴도 인식하나요?
FontSnap은 Google Fonts 패밀리와 비교합니다. 유료 글꼴의 경우 Google Fonts에서 가장 가까운 대안을 보여주며, 웹 프로젝트에는 대개 이것으로 충분합니다.

📍 어떤 문자를 지원하나요?
라틴 문자, 키릴 문자, 아랍 문자가 가장 정확합니다. 중국어와 일본어 지원은 아직 제한적입니다.

📍 내 데이터가 수집되나요?
아니요. 이 확장 프로그램은 개인 데이터를 수집하지 않으며 이미지를 어디에도 보내지 않습니다.

🌟 일상적인 디자인 작업을 위한 이미지 폰트 찾기 도구 FontSnap을 설치하고, "이 폰트 뭐지?"를 2초 만에 해결하세요. 텍스트를 선택하고, 결과를 확인하고, CSS를 복사한 뒤 바로 작업을 이어가세요.
