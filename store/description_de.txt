FontSnap ist eine KI-Schriftarterkennung aus Bild (font identifier from image), die direkt in Chrome läuft. Sie sehen eine schöne Schrift auf einer Website, in einem Banner oder auf einem Screenshot? Ziehen Sie einen Rahmen über den Text oder klicken Sie mit der rechten Maustaste auf das Bild, und dieser Font Finder zeigt die fünf ähnlichsten Google-Schriften.

🚀 Schriftart aus Bild erkennen in 3 Schritten
1️⃣ Klicken Sie auf das FontSnap-Symbol in der Symbolleiste oder drücken Sie Alt+Shift+F.
2️⃣ Ziehen Sie ein Rechteck über ein oder zwei Textzeilen, oder klicken Sie mit der rechten Maustaste auf ein Bild und wählen Sie Schriftart in diesem Bild erkennen.
3️⃣ Sehen Sie sich die Top-5-Treffer mit Live-Vorschau und Übereinstimmungswert an.

Kein Konto und kein Upload auf einen Server. Das neuronale Netz läuft lokal, daher bleiben bei dieser Schriftarterkennung aus Bild Ihre Bilder auf Ihrem Computer.

🔍 Was FontSnap anders macht
Die meisten Erweiterungen dieser Art lesen nur CSS und scheitern an Logos, Bildern, Bannern und Canvas-Text. FontSnap analysiert Pixel statt Code und funktioniert daher auch dort, wo CSS nichts verrät:
• Text in Bildern, Postern und Social-Media-Grafiken
• Screenshots von Apps, Folien und PDF-Seiten
• Hero-Banner und Anzeigen auf jeder Website

📌 Hauptfunktionen
- Bereichsauswahl auf jeder Seite: einfach über den Text ziehen.
- Kontextmenü: Schriftart aus Bild erkennen auf jeder Website, mit einem Rechtsklick.
- Upload-Modus als Font Finder per Bild: mit Strg+V einfügen, Datei ablegen oder Bild auswählen.
- Die Top 5 der ähnlichsten Schriften mit Übereinstimmungswert.
- Live-Vorschau jedes Treffers mit Ihrem eigenen Beispieltext.
- Fertige CSS-Zeile mit einem Klick kopieren.
- Funktioniert mit lateinischer, kyrillischer und arabischer Schrift.

🧠 Eine KI-Schriftarterkennung aus Bild, trainiert mit Tausenden Schriftschnitten
FontSnap nutzt ein kompaktes Modell zur Schriftenerkennung, das mit mehr als 3.600 Schriftschnitten trainiert wurde. Es fasst Schnitte zu Familien zusammen und liefert eine kurze, saubere Liste. So wird es zu einem praktischen Werkzeug für den Schriftvergleich: Ist die exakte Schrift kommerziell, erhalten Sie trotzdem die nächste Alternative, die Sie heute nutzen können.

⚡ Warum eine Online-Schriftarterkennung aus Bild nicht immer reicht
Web-Tools verlangen, dass Sie ein Bild speichern, hochladen und zuschneiden. FontSnap spart sich das:
▸ die Auswahl erfolgt auf der Seite, die Sie gerade ansehen;
▸ für Bilder auf der Seite genügt ein Rechtsklick;
▸ die Ergebnisse öffnen sich in einem neuen Tab neben der Quelle.
So passt die Schriftarterkennung aus Bild in den Browser, statt Sie aus ihm herauszuführen.

📊 Schriftart-Erkennung vs. CSS-Inspektor
Ein CSS-Inspektor liest die Stile von echtem Webtext, sieht aber keinen Text in einem JPG oder Canvas. Eine Schriftarterkennung aus Bild schließt diese Lücke.

🔒 Datenschutz zuerst
▸ Die Bildanalyse läuft per WebAssembly auf Ihrem Gerät.
▸ Ihre Screenshots verlassen nie den Browser.
▸ Von Google Fonts werden nur Familiennamen für die Vorschau abgerufen.
▸ Kein Tracking, keine Werbung, keine Anmeldung.

💡 Tipps für genaue Ergebnisse
• Markieren Sie ein oder zwei Textzeilen, nicht die ganze Seite.
• Ziehen Sie nur über Text, der auf dem Bildschirm sichtbar ist: FontSnap erfasst den aktuellen Viewport, nicht außerhalb gescrollte Inhalte.
• Große Schrift liefert genauere Ergebnisse als winzige Bildunterschriften.
• Passt der erste Treffer nicht, prüfen Sie die anderen vier: Die richtige Familie steckt oft in den Top 5.

❓ FAQ
📍 Was ist FontSnap?
Eine Chrome-Erweiterung und KI-Schriftarterkennung, die Schriften in einem markierten Bildschirmbereich, in einem Bild auf einer Webseite oder in einem hochgeladenen Bild erkennt.

📍 Wie kann ich eine Schriftart aus einer Bilddatei erkennen, also Schrift aus Bild finden?
Öffnen Sie FontSnap auf einer beliebigen Seite, wechseln Sie in den Upload-Modus und fügen Sie ein Bild mit Text ein, ziehen Sie es hinein oder wählen Sie es aus.

📍 Kann ich ein Bild auf einer Website prüfen, ohne es zu speichern?
Ja. Klicken Sie mit der rechten Maustaste auf das Bild und wählen Sie Schriftart in diesem Bild erkennen.

📍 Funktioniert FontSnap offline?
Die Erkennung selbst läuft lokal. Eine Internetverbindung wird nur für die Vorschauen von Google Fonts genutzt.

📍 Erkennt FontSnap kommerzielle Schriften?
FontSnap vergleicht mit Google-Fonts-Familien. Bei einer kommerziellen Schrift zeigt es die nächsten Alternativen aus Google Fonts, oft genau das, was man für ein Webprojekt braucht.

📍 Welche Schriftsysteme werden unterstützt?
Lateinische, kyrillische und arabische Schrift liefern die genauesten Ergebnisse. Chinesisch und Japanisch werden noch eingeschränkt unterstützt.

📍 Werden meine Daten gesammelt?
Nein. Die Erweiterung sammelt keine personenbezogenen Daten und sendet Ihre Bilder nirgendwohin.
