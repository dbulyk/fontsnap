FontSnap 是直接在 Chrome 中運作的 AI 圖片字體辨識工具（font identifier from image）。在網站、橫幅或螢幕截圖上看到喜歡的字型？只要拖曳框選文字，或在圖片上按右鍵，這款字體辨識工具就會列出最相近的五款 Google 字型。

🚀 3 個步驟完成圖片字體辨識
1️⃣ 點選工具列上的 FontSnap 圖示，或按下 Alt+Shift+F。
2️⃣ 拖曳框選一兩行文字，或在圖片上按右鍵，選擇選單項目（辨識這張圖片中的字型）。
3️⃣ 查看 5 款最相近的比對結果，並附上預覽與相符分數。

不需註冊帳號，也不會上傳到伺服器。神經網路在本機執行，因此進行圖片字體辨識時，您的圖片只會留在自己的電腦中。

🔍 FontSnap 有何不同
許多同類擴充功能只讀取 CSS，遇到標誌、圖片、橫幅和 canvas 文字就束手無策。FontSnap 看的是像素而不是程式碼，所以即使 CSS 無法提供任何資訊，也能運作：
• 圖片、海報和社群媒體圖像中的文字
• App、投影片和 PDF 頁面的螢幕截圖
• 任何網站上的主視覺橫幅與廣告

📌 主要功能
- 在任何頁面框選範圍：只要拖曳過文字就行。
- 右鍵選單：一鍵對任何網站上的圖片進行圖片字體辨識。
- 上傳模式（以圖找字型）：用 Ctrl+V 貼上、拖放檔案，或選擇圖片。
- 顯示 5 款相近字型，並附相符分數。
- 以自訂範例文字預覽每個相符結果。
- 一鍵複製現成的 CSS 程式碼。
- 支援拉丁文、西里爾文和阿拉伯文。

🧠 以數千種字型樣式訓練的 AI 找字體工具
FontSnap 使用精簡的字型辨識模型，訓練資料涵蓋超過 3,600 種字型樣式。它會把樣式歸類成字型家族，提供簡短清楚的清單。因此它是實用的字型比對與字體辨識工具：就算原本的字型是商用字型，您仍能得到今天就能使用的最接近替代字型。

🎨 誰會用這款圖片字體辨識工具
➤ 需要為客戶設計稿找到相近字型的網頁設計師。
➤ 想要 CSS 程式碼、而不只是字型名稱的前端工程師。
➤ 想重現橫幅風格的行銷人員與社群行銷專員（SMM）。
➤ 總是在問這是什麼字體的學生與部落客。
➤ 想不靠笨重的桌面軟體，就能以圖片查字體名稱的任何人。
➤ 想對掃描檔與螢幕截圖做以圖搜字體的研究人員。

⚡ 為什麼線上字體辨識工具不一定夠用
網頁工具要您先儲存、上傳、再裁切圖片。FontSnap 省掉這些步驟：
▸ 直接在您正在看的頁面上框選；
▸ 頁面上的圖片只要按一下右鍵就夠了；
▸ 結果會在來源旁邊的新分頁中開啟。
這是能融入瀏覽器的圖片字體辨識工具，不必繞到瀏覽器之外。

📊 字體偵測工具與 CSS 檢查工具的差別
CSS 檢查工具能讀取網頁上的文字，卻看不到 JPG 或 canvas 裡的文字。以圖片為基礎的字體偵測工具正好補上這個缺口。

🔒 隱私優先
▸ 圖片分析透過 WebAssembly 在裝置上執行。
▸ 您的螢幕截圖不會離開瀏覽器。
▸ 預覽時只會向 Google Fonts 請求字型家族名稱。
▸ 沒有追蹤、沒有廣告、不需註冊。

💡 取得準確結果的小技巧
• 選取一兩行文字，不要整個頁面。
• 只拖曳畫面上看得到的文字：框選只會擷取目前的可視範圍，不包含捲動到畫面外的內容。
• 大字比小字說明的結果更準確。
• 如果最上面的結果看起來不對，請檢查其他四個：正確的字型家族常常就在前 5 款之中。

❓ 常見問題
📍 FontSnap 是什麼？
它是 Chrome 擴充功能，也是 AI 圖片字體辨識工具，可辨識螢幕上選取區域、網頁圖片或上傳圖片中的字型。

📍 如何用圖片檔案做圖片字體辨識？
在任何頁面開啟 FontSnap，切換到上傳模式，然後貼上、拖放或選擇含有文字的圖片。

📍 不儲存圖片也能檢查網頁上的圖片嗎？
可以。在圖片上按右鍵，選擇辨識這張圖片中的字型。

📍 FontSnap 可以離線使用嗎？
辨識本身在本機執行。只有載入 Google Fonts 預覽時才會用到網路連線。

📍 FontSnap 能辨識商用字型嗎？
FontSnap 會與 Google Fonts 字型家族比對。遇到商用字型時，會顯示 Google Fonts 中最接近的替代字型，這通常正是網頁專案所需。

📍 支援哪些語言？
拉丁文、西里爾文和阿拉伯文的結果最準確。中文和日文的支援仍然有限。

📍 會收集我的資料嗎？
不會。此擴充功能不會收集個人資料，也不會把您的圖片傳送到任何地方。

🌟 安裝 FontSnap，這款適合日常設計工作的圖片字體辨識工具，把每次想問這是什麼字體的疑問，變成清楚的答案。框選文字、取得比對結果、複製 CSS，然後繼續設計。
