FontSnap என்பது Chrome-க்குள்ளேயே இயங்கும் AI எழுத்துரு கண்டறிதல் கருவி; படத்திலிருந்து எழுத்துருவைக் கண்டறிய உதவுகிறது (font identifier from image). இணையதளம், பேனர் அல்லது ஸ்கிரீன்ஷாட்டில் அழகான எழுத்துருவைப் பார்த்தீர்களா? உரையின் மேல் ஒரு பெட்டியை இழுக்கவும் அல்லது படத்தின் மீது வலது கிளிக் செய்யவும்; இந்த எழுத்துரு கண்டறியும் கருவி மிக நெருக்கமான ஐந்து Google எழுத்துருக்களைக் காட்டும்.

🚀 படத்திலிருந்து எழுத்துரு கண்டறிதல் 3 படிகளில்

🔍 FontSnap எப்படி வேறுபடுகிறது
இந்த வகை நீட்சிகள் பெரும்பாலும் CSS-ஐ மட்டுமே படிப்பதால் லோகோக்கள், படங்கள், பேனர்கள், கேன்வாஸ் உரையில் தோல்வியடைகின்றன. FontSnap குறியீட்டை அல்ல, பிக்சல்களைப் பார்க்கிறது; அதனால் CSS எதுவும் சொல்லாத இடங்களிலும் வேலை செய்கிறது:
• படங்கள், போஸ்டர்கள், சமூக ஊடக வடிவமைப்புகளுக்குள் உள்ள உரை
• ஆப்கள், ஸ்லைடுகள், PDF பக்கங்களின் ஸ்கிரீன்ஷாட்கள்
• எந்த இணையதளத்திலும் உள்ள ஹீரோ பேனர்கள், விளம்பரங்கள்

📌 முக்கிய அம்சங்கள்
- எந்தப் பக்கத்திலும் பகுதி தேர்வு: உரையின் மேல் இழுத்தால் போதும்.
- வலது கிளிக் மெனு: எந்த இணையதளத்திலும் ஒரே கிளிக்கில் படத்திலிருந்து எழுத்துருவைக் கண்டறியலாம்.
- பதிவேற்றப் பயன்முறை, படம் மூலம் எழுத்துரு தேடும் வசதி: Ctrl+V மூலம் ஒட்டவும், கோப்பை இழுத்து விடவும் அல்லது படத்தைத் தேர்ந்தெடுக்கவும்.
- பொருத்த மதிப்பெண்ணுடன் மிக நெருக்கமான 5 எழுத்துருக்கள்.
- ஒவ்வொரு முடிவையும் உங்கள் சொந்த மாதிரி உரையுடன் நேரடி முன்னோட்டம் பார்க்கலாம்.
- தயாராக உள்ள CSS வரியை ஒரே கிளிக்கில் நகலெடுக்கலாம்.
- லத்தீன், சிரிலிக், அரபு உரைகளுடன் வேலை செய்யும்.

🧠 ஆயிரக்கணக்கான பாணிகளில் பயிற்சி பெற்ற AI எழுத்துரு கண்டறிதல்
FontSnap 3,600-க்கும் மேற்பட்ட எழுத்து பாணிகளில் பயிற்சி பெற்ற சிறிய எழுத்துரு அடையாள மாதிரியைப் பயன்படுத்துகிறது. பாணிகளைக் குடும்பங்களாகத் தொகுத்து, சுருக்கமான, தெளிவான பட்டியலைத் தருகிறது. இதனால் இது நடைமுறைக்கு உகந்த எழுத்துரு பொருத்தும் கருவி ஆகிறது: சரியான எழுத்துரு கட்டணத்துக்குரியதாக இருந்தாலும், இன்றே பயன்படுத்தக்கூடிய மிக நெருக்கமான மாற்றை நீங்கள் பெறுவீர்கள்.

🎨 படத்திலிருந்து எழுத்துரு கண்டறிதலை யார் பயன்படுத்துகிறார்கள்
➤ வாடிக்கையாளர் மாதிரி வடிவமைப்புக்குப் பொருத்தமான எழுத்துரு தேவைப்படும் வலை வடிவமைப்பாளர்கள்.
➤ பெயர் மட்டுமல்ல, CSS வரியும் வேண்டும் என்று விரும்பும் ஃப்ரன்ட்-எண்ட் டெவலப்பர்கள்.
➤ பேனர் பாணியை மீண்டும் உருவாக்கும் சந்தைப்படுத்துநர்களும் SMM நிபுணர்களும்.
➤ இது என்ன எழுத்துரு என்று அடிக்கடி கேட்கும் மாணவர்களும் பதிவர்களும்.
➤ கனமான டெஸ்க்டாப் ஆப் இல்லாமல் படத்திலிருந்து எழுத்துருவின் பெயரை அறிய விரும்பும் அனைவரும்.
➤ ஸ்கேன்கள், ஸ்கிரீன்ஷாட்களில் படம் மூலம் எழுத்துரு தேடலை நடத்தும் ஆய்வாளர்கள்.

⚡ ஆன்லைன் எழுத்துரு கண்டறிதல் கருவி ஏன் எப்போதும் போதாது
இணையக் கருவிகளில் நீங்கள் படத்தைச் சேமித்து, பதிவேற்றி, வெட்ட வேண்டும். FontSnap அதைத் தவிர்க்கிறது:
▸ நீங்கள் ஏற்கெனவே பார்த்துக்கொண்டிருக்கும் பக்கத்திலேயே தேர்வு நடக்கிறது;
▸ பக்கத்தில் உள்ள படங்களுக்கு வலது கிளிக் போதும்;
▸ முடிவுகள் மூலப் பக்கத்தின் அருகிலேயே புதிய தாவலில் திறக்கும்.
இது உலாவிக்குள்ளேயே பொருந்தும் படத்திலிருந்து எழுத்துரு கண்டறிதல் கருவி; உலாவியை விட்டு விலகிச் செல்லும் சுற்றுப்பாதை அல்ல.

📊 எழுத்துரு கண்டறிதல் vs. CSS சரிபார்ப்பி
CSS சரிபார்ப்பி இணையப் பக்கத்தின் உண்மையான உரையைப் படிக்கும்; ஆனால் JPG அல்லது கேன்வாஸில் உள்ள உரையைப் பார்க்க முடியாது. படம் சார்ந்த எழுத்துரு கண்டறிதல் அந்த இடைவெளியை நிரப்புகிறது.

🔒 தனியுரிமைக்கு முன்னுரிமை

▸ உங்கள் ஸ்கிரீன்ஷாட்கள் உலாவியை விட்டு வெளியேறாது.
▸ முன்னோட்டங்களுக்காக Google Fonts-இடம் குடும்பப் பெயர்கள் மட்டுமே கோரப்படுகின்றன.
▸ கண்காணிப்பு இல்லை, விளம்பரங்கள் இல்லை, பதிவு செய்தல் இல்லை.

💡 துல்லியமான முடிவுகளுக்கான குறிப்புகள்
• முழுப் பக்கத்தை அல்ல, ஒன்று அல்லது இரண்டு வரி உரையைத் தேர்ந்தெடுக்கவும்.
• திரையில் தெரியும் உரையின் மேல் மட்டும் இழுக்கவும்: தேர்வு தற்போது தெரியும் பகுதியைப் பதிவு செய்யும், ஸ்க்ரோல் செய்தால் மட்டுமே தெரியும் உள்ளடக்கத்தை அல்ல.
• சிறிய தலைப்புகளை விடப் பெரிய உரை மிகத் துல்லியமான முடிவைத் தரும்.
• முதல் ஊகம் தவறாகத் தோன்றினால் மற்ற நான்கையும் பாருங்கள்: சரியான குடும்பம் பெரும்பாலும் முதல் 5-க்குள் இருக்கும்.
